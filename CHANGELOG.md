# Changelog

All notable changes to this project are documented here.

## [Unreleased]

No changes yet.

## [0.4.0] - 2026-10-31

### Added

- Task wizards for guest networks, port forwards, upstream DNS, WireGuard,
  Wi-Fi schedules, scheduled reboots, backups, safe package upgrades, and
  firmware image checks.
- Advanced network, bridge, VLAN, route, firewall zone, rule, and port-forward
  editors.
- Event timeline, per-client traffic, temperature, cellular, and WireGuard
  health alerts.
- Router profiles, read-only configuration comparison, version reporting,
  cross-platform CI, release archives, checksums, and user documentation.

## [0.3.0] - 2026-10-30

### Added

- Shared model overlays, preflight validation, smart post-apply checks, history,
  undo, drift detection, and masked git export.
- Health checks and one-key fixes for common router configuration problems.
- A merged client view with staged naming, reservations, blocking, and routing
  actions.

## [0.2.0] - 2026-10-28

### Added

- Live dashboard metrics for CPU, memory, traffic, interfaces, clients, and Wi-Fi.
- DHCP pools, static leases, and validated staged lease forms.
- Wi-Fi radio and network configuration forms with staged changes.

## [0.1.0] - 2026-10-28

Initial MVP release with SSH transport, OpenWrt capability detection, UCI
editing, staged changes with rollback, services, logs, packages, diagnostics,
and the terminal UI.
