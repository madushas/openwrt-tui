# Security Policy

## Supported versions

Security fixes are applied to the latest code on the `main` branch and the
latest published release.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use GitHub's
private vulnerability reporting for this repository when available. Otherwise,
contact the maintainer privately through the GitHub profile.

Include the affected version or commit, impact, reproduction steps, and any
safe mitigation. Please remove credentials, private keys, and identifying
router data from reports.
