# Contributing

Thanks for contributing to `owrt-tui`.

## Development

Install Go, then run:

```sh
make check
make build
```

Tests use scripted transports and do not require a router. Keep changes
focused, add or update tests, and update the README or changelog when user
behaviour changes.

## Pull requests

Explain the problem, the solution, and how you tested it. Do not include
router credentials, private keys, passwords, or unredacted router output.
